# Black Ops 3 Unlocker

Multiplayer and Zombies.

## What you get

```
Koschei BO3 Unlocker\
    Koschei BO3 Unlocker.exe
    Koschei BO3 Unlocker.dll
```

Keep both files in the same folder. They work as a pair.

## How to use it

1. Start Black Ops 3 and wait for the main menu.
2. Run **Koschei BO3 Unlocker.exe**.
3. Press **Inject**.
4. Go to the main menu for what you want to change. The Zombies tab needs the
   Zombies main menu, the Multiplayer tab needs the Multiplayer main menu.
   Rows pressed from the wrong menu do nothing.
5. Press **Insert** in the game to open the window. `Insert` again closes it.
6. Click what you want.
7. Press **Eject** in the launcher when you are done.
